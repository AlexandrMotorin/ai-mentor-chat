# Spring AI Mentor Chat

Мой личный учебный проект по интеграции искусственного интеллекта в Spring Boot.

Цель — глубоко разобраться в Spring AI (2025–2026) через практику.

## Что будем реализовывать (4 основные подзадачи)

1. Чат-бот с выбором модели
   → Переключение между OpenAI, Ollama (включая русские модели) и Anthropic через один интерфейс

2. RAG-чат с загрузкой документов
   → Загрузка PDF/Word, свой DocumentReader + DocumentTransformer, чанки, эмбеддинги

3. Агент с инструментами
   → Function Calling, @Tool аннотации, интеграция внешних API (погода, календарь и т.д.)

4. Чат с несколькими Advisor
   → Свои реализации Advisor: логирование, цензура, A/B-тестирование промптов

## Стек

- Java 21
- Spring Boot 3.4+
- Spring AI 1.1.x (стабильная версия)
- Maven
- Ollama (для локальных русских моделей: Qwen3, DeepSeek и др.)
